# Algo-Master-DSA

A personal collection of Data Structures & Algorithms problems and solutions, mostly solved from **LeetCode**, organized by topic for easy reference and revision.

## 📌 About

This repository is where I practice and track my DSA problem-solving journey. Each solution is written to be clean, well-commented, and includes a runnable `main()` function so it can be compiled and tested directly, without needing an external judge.

## 📂 Repository Structure

Problems are grouped by topic. Each file is named using the pattern `LC_<ProblemNumber>_<Problem_Name>.cpp`.

```
Algo-Master-DSA/
├── Arrays/
│   ├── LC_0001_Two_Sum.cpp
│   ├── LC_0283_Move_Zeroes.cpp
│   └── ...
├── (more topics coming soon: Strings, Linked Lists, Trees, Graphs, DP, etc.)
└── README.md
```

## 🚀 Getting Started

Each solution file is self-contained and includes a `main()` function with example input, so you can compile and run it directly.

```bash
# Clone the repository
git clone https://github.com/MdAshekMahmud/Algo-Master-DSA.git
cd Algo-Master-DSA

# Compile a solution
g++ -o solution Arrays/LC_0001_Two_Sum.cpp

# Run it
./solution
```

## 🛠️ Conventions

- **Language:** C++ (additional languages may be added over time)
- **Naming:** `LC_<ProblemNumber>_<Problem_Name>.cpp`
- **Structure:** Each file contains:
  - The core solution inside a `Solution` class (matching LeetCode's format)
  - A `main()` function demonstrating example usage
  - Brief comments explaining the approach, time, and space complexity
